# Ma Gestion Web

Page vitrine statique pour **Ma Gestion Web**.

Elle redirige les visiteurs vers l’application Wix Headless existante :

[https://headless-jzsfhrdevmx-guerrisseur-140b.wix-site-host.com/](https://headless-jzsfhrdevmx-guerrisseur-140b.wix-site-host.com/)

## Déploiement

Déployez ce dépôt sur Vercel en utilisant le framework **Other** (site statique). Le point d’entrée est `index.html`.

## Contenu

- `index.html` : page d’accueil et bouton d’accès
- `styles.css` : styles responsives

L’application Wix n’est pas recréée : cette page sert uniquement de porte d’entrée vers l’application existante.
